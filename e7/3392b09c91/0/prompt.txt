## Trigger model
Event-driven gateway, **multiple triggers**:
- **Slack @mentions** — `@hermes_agent <ask>` (interactive; gated by an allowed-users list, currently locked down).
- **Slack channel monitoring** — the `alert-monitor` plugin watches `#dev-ops` + `#supportdev` for keywords (error/fail/5xx/timeout/incident/outage…), forwards/rewrites hits into triage sessions, with 30-min dedup.
- **Dependabot PR review** — runs on a **2-hour timer** scanning open Dependabot PRs on `bigcartel/admin` (per ENG-5445). Not a GitHub webhook.

Hermes is built around MCP tool-use. Hard evidence:
- The alert-monitor plugin injects prompts telling the agent to *"Investigate using your **MCP tools (PagerDuty, AppSignal, Buildkite, Cloudflare, GitHub)**"* — so MCP servers are already configured.
- The dependabot skill uses the **GitHub MCP** (PR diff/CI reads, fetching Gemfile/Gemfile.lock) and drives BC's **minion/gru MCP endpoint** (`https://minion.bigcartel.dev/mcp`: `spawn_minion`, `push_file`, `minion_claude`, `destroy_minion`) to get an ephemeral credentialed dev env.
