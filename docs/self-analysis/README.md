# Generated self-analysis output

Everything in this directory except this file and `v2-audit-2/`/`v2-docs-review.md` is generated by `bundle exec rake woods:self_analyze`, which runs Woods' static analyzer over the gem's own source and renders the result as Mermaid. It is a maintainer diagnostic, not documentation for reading: regenerate it rather than editing it, and treat diffs here as analyzer-output changes, not content changes.

`architecture.md` is the single rendered artifact; it embeds the call-graph, dependency-map, and dataflow sections (standalone copies of those sections were removed for 2.0.0). The audit reports under `v2-audit-2/` and the documentation review are hand-written records, not generator output.

None of this directory ships in the packaged gem — `woods.gemspec` includes only top-level `docs/*.md`.
