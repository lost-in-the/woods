# Quick release-documentation audit protocol

Version 2026-09-21.1. Freeze before inference. Audit pinned Woods source revision
`c6f875ace375ee0263cc50762b054c9fc47296a1`; this is preparation evidence, not a
release transition or certification. No canonical page, version, generated fence,
plugin, release workflow, issue or publication is changed by this runner.

Select two coherent heading-content sections from each of 17 entry, canonical
and agent pages. The checked-in plan declares audience, purpose and selected
implementation/spec line spans. Sampling is deliberate, not random. Report every
selected and omitted section, line range, byte coverage and source hash. A parent
heading's introduction ends before its child heading. Recognize ATX headings
outside backtick/tilde fences; refuse unclosed fences. Never silently clip a
section, code fence, source span or request to meet the budget. Unsupported
Markdown constructs are not claimed as parsed semantic structure.

One request per selected section, one repeat: expected 34 requests, seven
independent questions each. Pin jev-1.13.0. Readability and relevance use separate
four-level Scores; larger means clearer/more relevant. Accuracy uses a separate
evidence-relation Choice and concrete-contradiction Noul. Three bounded block
Choices identify potential revisions and include none. Parallel questions do not
consume each other's results. A missing accuracy premise is unknown, not false
or passed; high distribution confidence is never verification. No combined score,
acceptance threshold, automatic edit, issue filing or release gate is introduced.

Whole file and exact selected-span hashes bind doc and evidence bytes to the
pinned clean checkout. All requests, rubric, selection, protocol and tool source
snapshots are frozen before capture. Local limits are 30,000 UTF-8 bytes for
state plus longest question and 60,000 for the full request; they are conservative
proxies, not the provider tokenizer. Stop on oversized packets and revise the
declared plan before capture, never in response to probabilities.

Reuse the retained Rails-bank transport and answer validator unchanged: one
credential lookup, HTTPS without automatic proxies/redirects, three workers,
raw response receipts, no retries, bounded two-decimal rounding diagnostics and
invalid Choice losers retained as invalid. Output is free and input cost is
estimated at $0.042 per million tokens, subject to the recorded model pricing.
Retain failed and partial requests in all denominators and preserve known usage.
CLI counters do not include independent audit effort. Raw artifacts are local,
not automatically published. No author/private app material is used.

After capture, independently investigate concrete accuracy leads against source,
registration and specs. Record exact doc/source lines and a reproduction when
needed. Separate confirmed false claims, missing evidence, unsupported model
leads and subjective readability/relevance suggestions. Scan the sampled scope
for obvious counterexamples even if the model returns none; do not claim a
complete tree audit or general model accuracy from this one run. Disclose that
source selection and adjudication are by the same coding agent; preserve model
signals separately. Any future rubric or scope change gets a new version/run.

Sources read for this method on 2026-09-21: TypeSafe HTTP API, Score, Choice,
model pricing, and citation-check cookbook. Its evidence-relation decomposition
is used; its demonstration auto-accept threshold is not adopted.
