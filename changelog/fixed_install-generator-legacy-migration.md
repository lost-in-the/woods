- `rails generate woods:install` writes `config/initializers/woods.rb` and nothing else, and needs railties only: the generator no longer loads Active Record at file load, so it runs in an application without it (#618). The legacy `woods_units`/`woods_edges`/`woods_embeddings` migration, which Woods 2's shipped paths never use, is written only with the new `--legacy-migration` option; without Active Record that option is refused before anything is written. The generated initializer no longer claims that installing the `tokenizers` gem gives exact token counts; counts are estimates unless a model-matched tokenizer is injected. The generator is now exercised for real in the suite (default, repeat, pretend and refusal runs on a railties-only bundle; the legacy migration under the Rails appraisal rows).
