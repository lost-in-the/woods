- `woods-extract` binds its capture to the physical application root (`File.realpath`) and the booted child compares its own root the same way, so a symlink alias passed to `--root` now verifies the boot boundary instead of silently publishing `boot_verified: false`; incremental paths named through the alias still resolve. A handed-off capture the child cannot consume is now reported once on stderr by the binding that failed (root, output, operation, rules, parent process, nonce, snapshot), never by value.
