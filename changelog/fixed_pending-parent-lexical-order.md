- A pending library class whose parent is named relatively (`class Child < Base` inside `module Outer; module Scope`) now gets its inheritance edge to the class Ruby binds. When `Outer::Scope` included a module that also defines `Base`, the edge pointed at that module's `Base` instead of `Outer::Base`, so the structural blast radius followed the wrong parent and missed the real parent's descendants. Each enclosing scope's own constants are now checked first, innermost out, then the innermost scope's ancestors, then the top level, matching Ruby's lookup order. Nothing is loaded and no autoload or `const_missing` runs.
