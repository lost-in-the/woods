- Index job classes a class macro generates with `Class.new` and `const_set` (for example `Widget::SyncNowWorker` from `async_method :sync_now`). The job unit points at the line that calls the generator, holds only the declaring line(s), and carries `metadata.generated` and `metadata.generated_by`; configuration and the perform signature come from the runtime class. Enqueue edges to these classes no longer dangle. A class bound by a generator outside the application still gets no unit.
