- Concerns kept under an autoload-only root (`app/views` by default) no longer disappear after a Rails reload (#1040). The configured component-directory walk now finishes right after the eager load, before path dispatch or any extraction family reads the shared concern classification, so full, concurrent, incremental and refresh runs classify in the same load state. An unrelated edit followed by a reload and an incremental run used to drop those concern units and keep them dropped until a full extraction. The walk therefore runs for every application, where it used to run only when a component base class (`ApplicationComponent`, Phlex, ViewComponent) existed: an application without components that puts `app/views` on an autoload path now has the Ruby files there loaded on every run, as its eager-loaded directories already are. A directory no autoload path owns is still never loaded, and `component_paths: []` still walks nothing.
