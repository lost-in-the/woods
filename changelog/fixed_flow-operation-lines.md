- Request flow operations now report the line in the file a reader opens, plus that file. Lines used to be counted in the unit's annotated `source_code` (route, filter and schema headers, inlined concern blocks), so an operation on line 37 of a controller could be reported as line 399. Extraction now records `metadata[:source_line_map]` for a unit whose annotated source moved its lines, and only for those units, so every other unit serializes byte-identically. Every flow operation gains a `file` key; an action defined in a concern reports the concern's file and lines, and the markdown flow shows `file:line` for an operation read from a file other than its step's.
