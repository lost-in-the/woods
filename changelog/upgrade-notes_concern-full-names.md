- `metadata.inlined_concerns` on model units now holds full concern names. An un-namespaced concern is unchanged (`Auditable`); a namespaced one changes from `MoneyColumns` to `Canopy::MoneyColumns`. A consumer that matched these entries by short name, or demodulized a concern unit's identifier to compare with them, should compare full names. Model units in an existing index keep the short names until each model is re-extracted; run `woods:extract` to rewrite them all at once. Controller units are unchanged.
