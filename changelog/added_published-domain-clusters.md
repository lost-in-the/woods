- `graph_analysis.json` now publishes `domain_clusters` and `stats.domain_cluster_count` (#799). Until now only the `domain_clusters` MCP tool returned them. These are the namespace-seeded clusters `GraphAnalyzer#domain_clusters` computes, over the application's own units: the types that carry a container, with source inside the application. Framework sources, engines, tests, configuration and gem-defined models such as `ActiveStorage::Blob` take no part. Each cluster also lists `typed_members`: each member's identifier with the type of its graph node. Full and incremental runs publish the same clusters for the same graph.
