- **Edge contract change:** each entry in a unit's `dependents` now carries `via`, the edge kind: `{ identifier, type, via }`. A caller that reaches a unit through two edge kinds (say `type_reference` and `code_reference`) still appears twice, but the rows are now distinguishable. The change is additive: readers that use only `identifier` and `type` are unaffected. See the published index layout.
