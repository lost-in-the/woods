- Every extraction serialized the dependency graph three times through a deep copy (the published file, the structural analysis and the summary read the same serialization): the internal readers now share the memoized serialization (`DependencyGraph#to_h(detached: false)`), the public `to_h` still returns a copy the caller may change. The dispatch rules' classification of a path, matched for every file at source capture, is kept between runs in one process for one rule set and configuration (`SourceInputs::Scopes.shared_rule_scopes`), so a resident process classifies a tree once. The in-memory vector kernel accumulates four products per loop iteration, in index order, so scores are unchanged and a 12,000 x 768 search measured 574 ms to 462 ms per query. On a synthetic 5,173-unit application a full extraction went from 14.1 s to 13.3 s and a one-model incremental run from 5.0 s to 4.6 s before the rule-scope memo.
