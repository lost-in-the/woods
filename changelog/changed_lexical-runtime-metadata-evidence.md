- Lexical `codebase_retrieve` writes a matched unit's runtime metadata as one line of JSON per entry, without empty values, and leaves out framework callbacks that record no side effect (it says how many; `lookup` still lists them). Pretty-printed in full, a model's metadata could take its whole share of the token budget and leave no room for its source. On the testbed's Canopy app the same 8,000-token answer went from 12 sources to 14 and the top model gained its source code.
- `recent_changes` adds a notice when the index's Git facts are `unavailable` or `degraded` (a shallow clone, a source archive), so an empty list is not read as "nothing changed".
