- Index MCP read tools (`lookup`, `search`, `dependencies`, `dependents`, `structure`, `graph_analysis`, `domain_clusters`, `pagerank`, `framework`, `recent_changes`, `trace_flow`, `diagram`, `woods_status`) accept an optional `root`, the path of a linked worktree of the served repository. One server then answers each call from that worktree's index, pinned to one generation. A path outside `git worktree list` is refused with `invalid_params` naming `root`. Calls without `root` are served as before, and `woods_status` gains a `worktrees` section listing each routable worktree with its generation, branch, SHA and watcher.
