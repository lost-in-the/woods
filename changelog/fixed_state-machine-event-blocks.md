- AASM and state_machines events are no longer merged or dropped by the event block scanner. A `do` in a comment or a string inside an event opened a block that nothing closed, so the next event's transitions were folded into it; an event closed by an `end` with trailing content (`end # pay`, `end)`) never closed; and an event still open at the end of the source was dropped. Comments and string contents are now ignored, any line starting with `end` closes a block, `if`/`case`/`begin` blocks inside an event are counted, and an event open at end of file is kept with the transitions read so far.
