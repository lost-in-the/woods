- AASM and state_machines events are no longer merged or dropped. Event blocks were found by matching keywords on each line, so a `do` in a comment or a string, a method named `class` (`object.class`) or a `:begin` symbol opened a block that nothing closed, and the next event's transitions were folded into it; an `end` with trailing content (`end # pay`) did not close the event. Events and their transitions are now read from the parsed source, so block boundaries come from the parser. An AASM model whose source does not parse still uses the line scanner, which now ignores comments and strings and keeps an event open at end of file with the transitions read so far.
