- Proc and lambda labels (model and mailer callback filters, controller filters and conditions, validation options, mailer defaults) no longer publish an absolute path for a callable defined outside the application. The lambda `dependent: :destroy` registers carried the host checkout's bundle path, so an index differed by machine and leaked local paths. A gem file is now named by its gem directory (`#<lambda activerecord-7.1.6/lib/active_record/associations/builder/association.rb:93>`, or `rails-<sha>/…` for a Bundler git checkout), a `path:` gem by its loaded spec, a standard-library file as `ruby/<path>`, and any other file by `external/<basename>`; application files stay root-relative. Re-extract to refresh the labels.
