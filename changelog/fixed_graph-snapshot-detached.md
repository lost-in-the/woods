- `Woods::DependencyGraph#to_h` returns a snapshot that is the caller's alone. Edge hashes were already copies, but their `target` strings were the live graph's, and the nodes, reverse, file_map, type_index and stats sections were the memoised hash's own containers, so appending to a snapshot's edge target rewrote what `dependencies_of` answered and every later `to_h`. Every container and every string is now duplicated. No shipped caller mutated a snapshot, so published output is unchanged.
