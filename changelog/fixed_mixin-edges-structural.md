- A constant written straight in `include`, `extend` or `prepend` now publishes an `include` or `extend` dependency edge instead of a `code_reference` one, for every unit type the source-reference pass covers (#959). Models, controllers and concerns already emitted these edges for their runtime mixins; mailers, jobs, services, POROs, lib units and the other class-based types did not, so `incremental_blast_radius_depth = :structural` stopped one hop short of, for example, a subclass mailer whose base mailer includes a changed concern. An identical edge an extractor already records is not added twice. The source reference cache moves to format 9, so the first incremental run on an older index asks for one full `woods:extract`.
