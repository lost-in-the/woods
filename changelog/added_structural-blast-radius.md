- `incremental_blast_radius_depth = :structural` bounds an incremental run's blast radius by edge kind instead of by hop count (#946, opt-in while it is measured). Inheritance, include and extend edges carry a change to any depth, so an STI grandchild still follows an edit to its grandparent; every other edge carries it one hop, and the walk stops there. The default stays the unbounded closure. A nested `has_many :through` is not covered; see `docs/INCREMENTAL_EXTRACTION.md`.
