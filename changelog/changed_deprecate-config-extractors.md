- `config.extractors` is deprecated. It never selected extractors, and it still does not: every extractor always runs in full, incremental, refresh and watch runs. An explicit assignment (the default list included) now prints one deprecation warning per process naming Woods 3.0 as the removal release. Woods' own defaults and a normal boot do not warn, and reading or assigning the option keeps working until then. Remove the line from your initializer. The configuration reference, initializer template and upgrade notes no longer promise a future selection feature.
