HTTP preflight and MCP dispatch now share an immutable Origin/Host policy for both Index and Console servers, including manually mounted Console middleware. Configured cross-origin entries match exactly, including explicit ports; portless entries also permit same-authority requests on other ports. Cross-port browser clients must list their actual origin. IPv6 host authorities and explicit default ports retain their configured meaning, malformed or blank headers are rejected, and SDK rebinding protection remains enabled. The Console transport now receives its configured origins and hosts instead of independently falling back to SDK loopback defaults.
