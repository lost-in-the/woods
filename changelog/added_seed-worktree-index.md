- `woods:seed[<other checkout's index>]` gives a new worktree an index by copying another checkout's published generation and running an incremental update for what differs, instead of a full extraction. The copy is built beside the output directory and published by renaming `generation.json` last. Manifest provenance and the recorded source root describe the new worktree. A seed from another Woods version, a dirty or moved checkout, an unknown commit, a changed boot input or a different configuration falls back to a full extraction and says why.
