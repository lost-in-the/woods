- The watch daemon marks its status `cycle: "extracting"` (with `cycle_kind` and `cycle_started_at`) while a cycle runs, because the extractor publishes `generation.json` before the daemon can write the cycle's outcome. `woods_status` reports the cycle, the `published_generation`, and `status_behind` when the status names an older generation than the one published, so a reader no longer takes the previous cycle's record for the current one.
