- A Ruby edit no longer re-extracts every Phlex and ViewComponent unit, and a Ruby edit under a component or `app/views` directory no longer re-extracts every controller. Both families re-run only when the edit touched a constant their render calls resolve, or touched an ancestor of their classes. The constants an edit touched are read from the syntax tree of the file before and after. A method body edit, or a new class that nothing renders, re-runs neither. An edit that cannot be read as constant definitions (a path outside `app/`, a syntax error, `const_set`, `autoload`, a method named like a constant) still re-runs both. Output is unchanged, and the incremental equivalence suite holds a shadowing class, a retarget through a changed base class and an unreadable edit to a full extraction (#728).
