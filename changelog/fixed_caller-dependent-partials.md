- A relative partial rendered from a directory no controller owns now resolves through the pages that render it. `shared/_navigation` rendering `"account_head"` is found by Rails through the view prefixes of whichever controller renders the page, so `ViewTemplateExtractor` takes the owners (controllers or mailers) that reach the template through render edges and layouts, and resolves the name through each owner's prefixes. When they agree on one file the `render` edge targets it. Otherwise no edge is recorded and the name is listed under `metadata.unresolved_partials` as `{ kind: "caller_prefix", name:, candidates: }`. A relative partial with no file anywhere no longer leaves an edge to a template that does not exist. `render template: "layouts/<name>"` now records a `render` edge to that template, so a layout that renders another layout carries its controllers' prefixes through to the partials the inner layout renders.
