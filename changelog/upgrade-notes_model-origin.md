- Model unit payloads gain one key, `metadata.origin`; no existing key changes. Run a full `woods:extract` after upgrading: an incremental run adds the field only to the models it re-extracts. Treat a missing `origin` as `unknown`. An impact report whose range crosses the upgrade lists `origin` as a changed, unclassified metadata key on every model. `origin` describes the class, not `file_path`: a reopened gem model reads `gem` with an application `file_path`.
