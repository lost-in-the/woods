- Units that reach a controller through a route helper now publish `metadata.route_helper_references` (woods#795): each `_path`/`_url` helper resolved through the live named-route map, with its route name, controller, action, verb, path and `via` (`link_to`, `redirect_to` or `form_action`). Navigation edges are unchanged and still name only the controller; before this, every helper after the first one per controller was dropped. Controllers, mailers, Phlex and ViewComponent components and view templates publish it when `extract_navigation_edges` is on. Run a full extraction to populate retained indexes.
