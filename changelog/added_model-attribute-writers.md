- Model units now record `metadata.attribute_writers` (woods#797): every attribute an instance accepts through a public writer, read at runtime. The list includes writers from the class body, concerns and other modules (association and collection-id writers, nested attributes, `has_secure_password`, store accessors, `attr_accessor`), plus attribute names and aliases whose writers Rails generates lazily. Writers that `ActiveRecord::Base` itself defines are left out. Woods Map uses it to check permitted params against the model. Additive: `instance_methods` is unchanged.
