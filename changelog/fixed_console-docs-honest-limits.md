- The Console documentation no longer overstates its protections. `SECURITY.md` now states the limits of redaction, scanning and rollback, and that running the Console in production is at the operator's own risk. The setup guide matches that development/staging guidance, no longer claims generic high-entropy token detection, and the troubleshooting page qualifies the statement timeout by adapter. The `console_sql` tool description and the Rack middleware notes now say the rollback covers the request's own database connection, not callbacks, other connections or external effects.
