- `woods:watch` no longer loses a stop request. A stop that arrived while a cycle was demanding a restart used to be overwritten, so the daemon reported `restart_required` instead of `stopped`; a stop now wins over a restart or the idle timeout, whichever lands first. A stop that arrived before the daemon had built its file watcher also used to reach nothing, and the watcher started afterwards kept the daemon running; that watcher is now never started.
