- Model event flows (`Post@create`) now treat a callback that an inlined concern defines as application code. Before, the model's `source_code` carried the concern only as a comment block, so such a callback was marked `unexpanded: "not defined in the unit"` like a framework callback. The operation now names the concern in `defined_in`, and the flow expands it in the concern unit (`Taggable#normalize_tags`). This was found by Woods Map's M3 check of its Lifecycle diagrams against flow documents.
