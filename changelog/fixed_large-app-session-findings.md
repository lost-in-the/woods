- Compact `lookup` ranks a unit's own matching methods ahead of the concerns inlined into it.
  A concern block holds a whole module and so matched more query terms than any one method;
  a few concerns could take the budget while the unit's matching action was omitted.
- `lookup` says what to do when `budget` or `query` is passed without compact or outline evidence,
  and the schema states that a full lookup refuses them.
- A rake task unit's source names the line of the file that defines the task.
  The unit still carries the whole rake file, because a task calls the helpers its file defines.
