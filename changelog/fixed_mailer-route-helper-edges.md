- Mailer and ViewComponent `_path`/`_url` references no longer record a `via: :url_helper` edge to a route name that matches no unit. A helper naming a live route already targets the controller that route dispatches to (`via: :link_to`); a name with no live route now records no edge. The shared navigation scan also stops reading a keyword label (`base_url: host`) or a method the source defines (`def tracking_url`) as a route helper. A shorthand keyword with no value (`t('.notice', widgets_path:)`) passes the helper's result, so it still counts as a call.
