- Add `config.rake_task_paths` (default `lib/tasks/**/*.rake`, `rake/**/*.rake` and `Rakefile`) to choose the files `RakeTaskExtractor` reads. Tasks in a root `rake/` directory and in the `Rakefile` are now indexed. Each entry is a relative file path, `dir/**/*.ext` or `dir/*.ext`; the setter raises `Woods::ConfigurationError` for anything else and keeps the previous value. The same entries drive incremental dispatch and the watch daemon, which re-extracts a change under any configured directory. Changing the value needs a full extraction.
