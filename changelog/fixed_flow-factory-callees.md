- Request flows no longer expand FactoryBot factories as callees. A lowercase receiver (`shipment.dispatch!`) used to resolve by name to the factory of the same name and appear as a `factory` step in controller flows. A flow callee now has to be a constant-shaped receiver (`Ledger`, `Billing::Ledger`), and a unit that exists only for the test suite (`factory`, `test_mapping`) is never a callee.
