- A constant read through a unit's class credits the unit (LOS-126). `Kit::Button::VARIANTS`, `::CoreModel::UNSHIPPED` and `Library::Book::STATES` now resolve to `Kit::Button`, `CoreModel` and `Library::Book` in the constant-reference pass: the path is cut back while it names a value, the first class or module reached is the target, its `metadata.references` span covers the class path as written and carries no `method`. A class or module nested in a unit (`Kit::Button::Icon`) is its own constant and credits nothing but itself, so the regex model scan no longer links a model for `Library::Book::Chapter.new` when `Chapter` is a loaded class or module; a value or an unloaded name read through the model still does.
