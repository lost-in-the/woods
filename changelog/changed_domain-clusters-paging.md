- `domain_clusters` now pages its output. It returns the 20 largest clusters by default (`limit`, `offset`), in a stable order (member count, then name), and lists at most 50 members, entry points and boundary edges per cluster (`member_limit`) with `members_omitted`, `entry_points_omitted` and `boundary_edges_omitted` counting the rest. `total` is still the number of clusters, and the shared `completeness` object reports `total_matches` and `has_more`. Set `WOODS_DOMAIN_CLUSTERS_LIMIT` and `WOODS_DOMAIN_CLUSTERS_MEMBER_LIMIT` to change the defaults. Clusters are computed once per published generation and exact `min_size` and `types`, so paging does not recompute them. The Markdown and plain renderers show the page position and omitted members.
