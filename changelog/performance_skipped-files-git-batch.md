- An incremental cycle no longer spends one `git check-ignore` process per untracked or ignored configuration source building `skipped_files.json` (#721). `GitSourceFilter#skip_reasons` asks about every untracked source in one `git check-ignore --stdin -z` call and keeps the answers for the process until one of Git's inputs changes: the index, a `.gitignore` above a source, `info/exclude`, the Git configuration or the global excludes file it names (`GitIgnoreInputs`). A cycle over an unchanged tree now builds the report with no `git` process; after an index change it takes three (two `ls-files`, one `check-ignore`), whatever the number of sources. A fixture with 33 untracked or ignored sources went from 35 processes on every cycle to 0, or 3 after a `git add`. The report's content is unchanged. An edit to a file the configuration includes (`include.path`), or to a system configuration outside `/etc/gitconfig` without `GIT_CONFIG_SYSTEM`, is seen with the next index change.
