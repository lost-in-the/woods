- `RakeTaskExtractor` parses with Prism instead of matching lines. A `task_dependency` edge now targets the task Rake would resolve from the enclosing namespace (`task build: :compile` inside `namespace :js` points at `js:compile` when that task exists) while `metadata.task_dependencies` keeps the names as written. `metadata.task_dependencies` and `metadata.description` merge every definition of a reopened task. A task whose name is computed (`task "sync_#{name}"` in a loop) is indexed when the Rake application of the extracting process loaded the file, with `metadata.name_source: "runtime"`; everything a file states literally is read from the file, so output does not depend on which process runs the extraction.
