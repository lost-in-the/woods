- Extract three module shapes that produced no unit (#673). An `ActiveSupport::Concern` that no model includes becomes a `poro` module unit when it has a `ClassMethods` method or an `included` / `prepended` block, with `active_support_concern: true` and the `ClassMethods` names in `class_methods`. A singleton method wrapped by a prepended memoizer, or redefined in place by a helper in another file, still counts when the module body declares it with `def`. A constant-only module becomes a unit with its constants in `metadata[:constants]`. A namespace file whose governed constant is a module now also emits the classes nested in it that define a method. Namespace-only modules remain excluded.
