- Index the Ruby an application boots, seeds and builds from as `configuration` units (#678). On top of `config/initializers` and `config/environments`, the configuration extractor now covers every Ruby file directly under `config/` (`config_type` `boot`, `environment`, `importmap`, `deploy`, or plain `configuration`), `config/deploy/**`, `db/seeds.rb` and `db/seeds/**` (`seeds`), and the root `Gemfile` (`gemfile`, with an edge to each gem it declares) and `Rakefile` (`rakefile`). `config/routes.rb` stays with the route extractor and `config/application.rb` with the behavioral profile.
