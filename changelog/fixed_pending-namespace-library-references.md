- A library class under a namespace nothing has loaded yet (a compact `module A::B` declaration in an autoloaded `lib/`, where Zeitwerk registers `A` as a pending autoload) is now a reference target. The constant lookup used to drop the pending-autoload evidence at the unloaded segment, so every reference to such a class was discarded: no source-reference span and no `code_reference` edge, and the class was missing from its callers' dependents and blast radius. On one field app that was 56% of lib units (#956). The library is matched only when it is a `lib` unit whose static declaration names it and whose file is where the namespace's absolute autoload path puts it (Zeitwerk's file-to-constant convention); a relative path, another file, another unit type or an identifier published twice still stays unresolved.
