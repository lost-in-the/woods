- A saved impact report whose writer died part-way (a `SIGKILL`, an OOM kill, a container restart) no longer wedges its report ID. A report is now written into a private staging directory under `explorer/impacts/` and renamed into place whole, so a crash leaves nothing at the report's path, and the next save of that report removes the dead writer's staging directory. A report directory an older version left without its `impact.json` is recognized and replaced too, instead of being refused as a conflicting report on every later save; a directory holding anything a writer does not make is still kept and refused.
