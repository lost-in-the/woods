- `woods:validate` and `woods_status` report whether the index can take an incremental run (`Incremental: ready` or `needs full extraction (<reason>)`, `index.incremental` in the status payload), separately from whether it is readable. Reasons cover a legacy flat layout, a 1.x writer, an unreadable manifest and a missing or malformed source reference cache, which is read through the writer's own cache reader. Older indexes still pass validation, the incremental writer still refuses before publishing, and its refusal messages now point at `woods:validate`.
