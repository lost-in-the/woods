- `woods:markdown` exports extraction data as a folder of plain Markdown notes with relative Markdown links, replacing the Obsidian-only export as the supported export path. `WOODS_MARKDOWN_OBSIDIAN=1` selects the Obsidian flavor (wikilinks, tags, aliases, callouts, `.obsidian/` config and `Units.base`). Settings read `WOODS_MARKDOWN_DIR`, `WOODS_MARKDOWN_INCLUDE_SOURCE`, `WOODS_MARKDOWN_INCLUDE_FRAMEWORK` and `WOODS_MARKDOWN_FORCE_PURGE`, falling back to the matching `WOODS_OBSIDIAN_*` variable. `Woods::Obsidian::VaultExporter` takes a new `obsidian:` keyword that defaults to `true`, so direct callers keep their output.
