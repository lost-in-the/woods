- Library classes now carry their `:inheritance` edge (#965). A library is usually still a pending autoload during extraction, so the runtime lookup the edge relied on found nothing and no library unit got one. The parent is now read from the class's own declaration and resolved lexically against what the runtime defines or registers, without loading either class. A parent that overrides `self.name` no longer produces a dangling edge: the edge names its constant, for every unit type, controllers and mailers included. A library declared as `module A` then `class B::C` is now a reference target (#956). On a production app, 105 library units had a published parent and no edge, and 99 PORO edges pointed at no unit; `:structural` incremental runs and `dependents` answers could not reach those children.
