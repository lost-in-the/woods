- A reused `Woods::Extractor` instance no longer leaks one run's state into the next. A full extraction no longer keeps the previous run's results, so an extractor the configuration had since disabled, such as `rails_source` after turning off `include_framework_sources`, no longer has its earlier units written. An incremental or refresh run no longer sees the previous full run's in-memory results, which could make `SUMMARY.md` report stale totals.
