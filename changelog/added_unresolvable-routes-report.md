- `graph_analysis.json` gains an `unresolvable_routes` section (with `stats.unresolvable_route_count`) listing routes whose controller has no indexed unit (`missing_controller`) or whose action is not among the controller's actions (`missing_action`). The report is computed from the dependency graph, which now records `actions` on controller nodes and `route_action` on route nodes, so it follows controller edits in incremental runs without re-extracting routes. Controllers a gem or engine defines are not reported, and routes with no controller or action (mounts, redirects, Rack endpoints) are skipped. `woods:validate` prints one warning per entry; its exit status is unchanged.
