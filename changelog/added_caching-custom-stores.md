- `CachingExtractor` records calls on cache stores a Ruby file obtains itself, not only `Rails.cache`: a local, instance or class variable, constant, or method assigned from `.cache_store`, `ActiveSupport::Cache.lookup_store`, or `ActiveSupport::Cache::*Store.new`, or such an expression chained directly. Their `read`, `write`, `fetch`, `delete`, and `exist?` calls appear in `cache_calls` with key, TTL, and options like `Rails.cache` calls, plus a `store` field naming the receiver, and count as low-level caching. A file whose only cache use is such a store is now a caching unit.
