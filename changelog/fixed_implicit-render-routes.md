- `woods:validate` and `graph_analysis` (`unresolvable_routes`) no longer report a routed action Rails serves by implicit render as `missing_action` (#726). A non-partial view template named for the action, in any format or handler (`show.html.erb`, `index.haml`), owned by the controller or by a controller it inherits from, resolves the route. A controller that defines `action_missing` (now recorded as `metadata.action_missing: true` and on its graph node) resolves every routed action. The graph cannot tell whether a controller renders implicitly at all, so a template beside an `ActionController::API` controller still resolves its action.
