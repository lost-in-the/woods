- Lines that reach a reader now carry the file's own line beside the annotated one. Method table entries, callback and filter `declaration` sites and test examples gain `file_line`/`file_end_line`, and reference spans in the unit's own file gain `file_line`. `line` counts lines of the published `source_code`, which includes Woods' headers and inlined concern blocks, so it was offset from the file an agent opens: by the header length, and by hundreds of lines below an inlined concern. A definition inside an inlined concern block reports the line in the concern's own file, with `file_unit` naming that concern. A line Woods added, or a line of a library unit's secondary contributor file (see `source_contributors`), reports a null `file_line`. `docs/INDEX_LAYOUT.md` describes both line systems. Markdown `lookup` output prints the file lines first and labels the annotated ones as published source lines.
