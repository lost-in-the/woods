- Application units now record the size of their own source file as `metadata.source_size` (#810): `lines`, every line, and `loc`, the lines with anything but whitespace. Their graph nodes record both as `lines` and `loc`. The count is of the file, not of the unit, so a model's inlined concerns are not added and two units read from one file carry the same numbers. Routes, framework and gem sources, engines, configuration, migrations and tests carry no size. With Packwerk packages, `graph_analysis.json` gains `package_sizes`: each package's distinct files, `lines`, `loc`, and `loc` by unit type. Full and incremental runs publish the same values. See [Source size](docs/EXTRACTOR_REFERENCE.md#source-size).
