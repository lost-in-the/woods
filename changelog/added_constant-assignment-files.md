- Extract top-level constant assignment files (#672). A swept or `app/models` file with no class or module body, such as `EmailPattern = /.../` or `Gateway::Billing::Countries = %w[...].freeze`, now yields one `poro` unit per assignment it canonically owns, with `metadata.ruby_kind: "constant"` and `metadata.value_kind` (`regexp`, `array`, `hash`, `string`, `symbol`, `number`, `range`, `boolean`, `nil`, or `expression`) read from the syntax. Module aliases and constants another file owns are skipped. `ActionController::Metal` subclasses are no longer emitted by the sweep.
