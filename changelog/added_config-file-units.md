- Index YAML configuration and application data files as `config_file` units (#678). Every file under `config.config_file_paths` (default `config/*.yml`, `config/**/*.yml` and `app/data/**/*.yml`, never `config/locales`) becomes one unit identified by its root-relative path, with its top-level keys, environment sections, per-environment keys, dotted key paths, ERB use and the environment variables the ERB names. The file's text is never published: `source_code` is an outline of key paths, so comments and values stay out of the index. `config.config_file_values = true` opts in to leaf values, and a value under a credential-named key, a credential-shaped value and ERB source are still replaced by a marker. A key shaped like a credential is redacted in either mode. Secret-bearing files (`credentials*`, `secrets*`, `*.enc`, `*.key`, anything under `config/credentials/`) are never opened, whatever the globs say. ERB is never evaluated and YAML is read as a syntax tree.
