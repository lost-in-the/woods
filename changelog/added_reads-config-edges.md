- Link code to the configuration files it reads with `reads_config` edges (#678). `config_for(:name)`, `YAML.load_file` / `safe_load_file` with a literal or `Rails.root.join` literal path, and reads through a constant listed in `config.settings_readers` (for example `[{ constant: "Settings", file: "config/settings.yml" }]`) each add an edge from the reading unit to the `config_file` unit, so `dependents` on a configuration file lists its readers. The target comes from the reader's own source and configuration, and a path that is not an indexable configuration file yields no edge.
