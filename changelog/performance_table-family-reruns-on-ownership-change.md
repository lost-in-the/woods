- A model edit no longer re-runs the table, migration, database view and external consumer extractors unless the live table catalog differs from the published table units. A body-only edit, the common case, leaves all four alone. An ownership move re-runs the tables, migrations and database views; declared external consumers re-run only when the set of table identifiers changes. Schema dumps and migration files still re-run the whole family. Output is unchanged, and the incremental equivalence suite holds a model moved to another table and a model toggled abstract to a full extraction (#737).
