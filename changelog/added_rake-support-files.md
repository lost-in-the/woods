- Index Ruby files under a rake directory (helper modules, core extensions) as `rake_task` units with `metadata.kind: "rake_support"`, identified by their root-relative path, with the modules, classes and methods they define in `metadata.constants` and `metadata.methods`. A task gains a `method_call` or `code_reference` edge to each support file it calls into or names. Files another extractor owns (a rake directory inside `lib/`) are left to that extractor.
