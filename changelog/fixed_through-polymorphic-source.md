- Treat a `through` association whose source is polymorphic as an interface. `has_one :referrer, through: :account_referral, source: :referrer` over a polymorphic `belongs_to :referrer` recorded a `has_one` edge to `Referrer`, which names no single class. It now follows the polymorphic `belongs_to` rule: the name joins `metadata[:polymorphic_interfaces]`, and an edge is emitted only when the application defines a constant of that name.
