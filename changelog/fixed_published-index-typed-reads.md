- `Woods::PublishedIndex#unit(identifier, type:)` and `#units` now read unit bodies through the MCP reader's guarded typed path instead of a duplicate: a symlinked type directory or unit file, a unit body naming another identifier, or an indexed identifier whose unit file is missing, raises `IOError` instead of being served to (or silently dropped from) RuboCop cops and gate scripts. The `graphql`/`rails_source` family aliases keep their PublishedIndex meaning, and a `generation.json` that parses but names no valid generation now raises `CorruptPointerError`.
