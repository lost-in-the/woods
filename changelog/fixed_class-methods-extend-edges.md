- Point `extend` edges at the mixin that owns a `ClassMethods` module. A model extending `Mixin::Persistence::ClassMethods`, or the implicit `ClassMethods` of a concern's `class_methods do` block, recorded an edge to `…::ClassMethods`, which is never a unit. The edge now targets the owning module, and a concern's `extend ClassMethods` of its own module records no edge. A module whose `ClassMethods` live models extend is now discovered as a `concern` unit wherever the application declares it, including a file under `config/initializers/`. Run a full extraction to replace the affected edges.
