- Record the literal commands a rake task runs in `metadata.shell_commands`: arguments to `sh`, `system`, `exec`, `spawn` and `Open3`, backtick and `%x` strings, and string arguments to helper methods defined in the rake files or their support files that shell out themselves. Credentials are redacted before publication: everything `ConfigSourceGuard` withholds (known credential shapes, URL userinfo), the value of a credential-named `NAME=value` assignment or `--flag`, the value after `Bearer` or `Basic` or of a credential-named header, the password of `-u user:password`, the password flag of tools that take one (`mysql -p`, `sshpass -p`, `docker login -p`, `redis-cli -a`), credential-named query parameters, and credential literals inside a quoted argument such as a JSON body. A quoted value with spaces is redacted whole. Each command is then cut to 200 characters. No edges are added.
