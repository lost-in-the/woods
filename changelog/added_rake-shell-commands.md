- Record the literal commands a rake task runs in `metadata.shell_commands`: arguments to `sh`, `system`, `exec`, `spawn` and `Open3`, backtick and `%x` strings, and string arguments to helper methods defined in the rake files or their support files that shell out themselves. Credentials are redacted before publication: everything `ConfigSourceGuard` withholds (known credential shapes, URL userinfo), the value of a credential-named `NAME=value` assignment or `--flag`, the word after `Bearer` or `Basic` or a credential-named header, the password of `-u user:password`, and credential-named query parameters. Each command is then cut to 200 characters. No edges are added.
