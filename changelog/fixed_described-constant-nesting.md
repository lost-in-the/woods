- A constant described inside a `module` block in a spec is resolved as Ruby resolves it: through the file's lexical nesting, innermost scope first, against the loaded constants. `module Nested; describe AssignPositions do` targets `Nested::AssignPositions`; `module Spree; describe Spree::Order` targets `Spree::Order`, not `Spree::Spree::Order`; and `module SpecHelpers; describe Widget` targets a top-level `Widget`. The nesting is prefixed only when nothing loaded resolves.
