- Model units carry `metadata.origin` (#995): `app`, `framework`, `gem` or `unknown`, from the file that first defined the model's constant, by the same rules as callback `origin`. A gem model the application reopens stays `gem` while its `file_path` names the application file. A pending autoload, a class Ruby has no source site for, or a name that now resolves to another class is `unknown`, and nothing is loaded to decide. No model is hidden. The extractor reference no longer says models must be table-backed: every named, non-abstract `ActiveRecord::Base` descendant except `HABTM_` join classes is extracted, with or without a table.
