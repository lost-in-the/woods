- Every `_index.json` entry now names its unit `type` (#828), written from the same unit on the full and incremental paths, and `PublishedIndex#units` labels an entry of a shared type directory (`routes/`, `rails_source/`, `graphql/`) from it instead of opening the unit. Listing every unit of a ~10,000-unit index with ~3,700 routes drops from about 420 ms to about 40 ms. An index written before this change, or an entry naming a type its directory cannot hold, is still labelled by the guarded unit read.
