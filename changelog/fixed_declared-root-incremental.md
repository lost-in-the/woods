- A Ruby file under a declared source root (`woods-extract --source-root PATH`, the manifest's `extra_roots`) is now incremental input everywhere a change is classified: the launcher, `woods:hook_refresh` and the plugin hook, `woods:incremental` and the watch daemon (which no longer depends on an `app/` edit sharing the batch). An incremental run that consumes such a file refreshes its declared-scope identity so `woods:source_status` returns to `current`, and the hook task prints one stderr line naming any Ruby path it dropped and the roots it knows. Previously a declared-root edit was dropped with no output.
