- The `notion_sync` MCP tool no longer reports `synced: true` for a run that hit errors. The result now carries `status` (`complete`, `partial` or `failed`) and `error_count`, the total number of errors before the listed `errors` are capped at ten. `partial` means some pages were written or already up to date, `failed` means none were, and `synced` is false only for `failed`. `Woods::Notion::Exporter#sync_all` also returns `error_count`.
