- The `notion_sync` MCP tool no longer reports `synced: true` for a run that hit errors. The result now carries a `completeness` hash in the same shape as `search`: `status` (`complete`, `partial` or the new `failed`, which search never emits), `reason` (`exhausted`, `page_errors` or `nothing_synced`), `has_more` and `total_errors`, the error total before the listed `errors` are capped at ten. A non-complete run also sets `partial: true` and a `hint`. `synced` is false only when nothing synced. `Woods::Notion::Exporter#sync_all` also returns `error_count`.
