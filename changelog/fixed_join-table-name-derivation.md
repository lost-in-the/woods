- `create_join_table` is read with the table name Rails gives it. `create_join_table :catalog_categories, :catalog_products` was recorded as `catalog_categories_catalog_products`; Rails writes the prefix the two tables share once, `catalog_categories_products`. A `table_name:` option now overrides the derived name, so the migration's `tables_affected` and its `:migrates` edge point at the table that exists instead of listing it as unresolved.
