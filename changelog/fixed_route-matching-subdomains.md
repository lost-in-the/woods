- A literal path in a feature, system or request test is matched the way Rails routes it: among the routes it fits, in route order, using the subdomain the file names (`host!`, `Capybara.app_host`, a `subdomain:` option, or a helper from `config.test_subdomain_helpers`). When the subdomain is unknown, one static route wins over `/:param` and `*glob` routes; anything still undecided is recorded as `routes_ambiguous` with no edge.
  Paths inside `redirect_to`, `have_current_path`, `assert_redirected_to` and `assert_current_path` are recorded as `routes_asserted`, not as exercised.
