- Redact credentials in published configuration source (#678). The source of `configuration` and `route_file` units passes four checks before it reaches the index: the Console credential scanner (known credential shapes, including URL-encoded and base64-wrapped ones), URL userinfo in any scheme with or without a password, private key blocks, and a string literal assigned to or passed after a credential-named key on the same line (`password: "..."`, `ENV["API_TOKEN"] = "..."`, `set :password, "..."`). Each match is replaced by a marker and the rest of the source is untouched. Redaction is best-effort: a credential with no recognizable shape under a name that says nothing is not detected. Boot, seed, deploy, root and route files must also resolve under the application root, so a symlink that leaves it is not read.
