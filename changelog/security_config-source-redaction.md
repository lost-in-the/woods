- Redact credential-shaped text in published configuration source (#678). The source of `configuration` and `route_file` units is passed through the Console credential-shape patterns, plus `scheme://user:password@` userinfo in any scheme and private key blocks, before it reaches the index, so a token in a Gemfile source URL, a deploy password or a key in an initializer is replaced by a marker. Boot, seed, deploy, root and route files must also resolve under the application root: a symlink that leaves it is not read.
