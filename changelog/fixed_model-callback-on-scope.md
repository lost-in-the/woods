- Model callbacks declared with `on:` now publish it as `conditions.on` (`after_commit :notify, on: :create` gives `["create"]`). The scope was lost: Rails encodes it as a generated lambda, which appeared as an opaque `"Proc"` under `conditions.if`. It is read from the lambda's captured local (`fire_on` for commit callbacks, `options[:on]` for validation callbacks) without calling it, and the generated lambda is no longer listed under `if`. Re-extract to refresh model units.
