- Publish verified `code_reference` edges from every constant-owned unit type (#655). Phlex components, view components, GraphQL types, mutations, resolvers and queries, mailers, serializers, decorators, validators, policies, managers and channels are now callers in the source-reference pass, beside models, controllers, services, POROs, library units, concerns and jobs. `dependents` of a model or service now lists the components and GraphQL units that read it, and a GraphQL unit follows a constant created after it without its own file changing.
  Each caller type has an explicit list of target types. By default a component adds no `code_reference` edge to another component, and a GraphQL unit adds none to another GraphQL unit: `render`, `slot`, `type_reference` and `field_resolver` edges already state those relationships. Every other pair is on.
  Expect the edge count to rise. On the test application scaled to 1,200 components with 9 non-component references each, the pass added 10,799 component edges (2,414 to 13,213 edges in total) and its full-extraction time went from 0.6s to 1.0s.
