- A model whose table is absent and that subclasses another model (such as a framework model the application never installed) no longer fails extraction with a logged error. Rails decides `descends_from_active_record?` from the table's inheritance column and raised; the extractor now answers from the class tree, extracts the model with `table_exists: false`, and no longer marks the models extractor's consumption unverified, which had kept source freshness from ever reaching `current`.
