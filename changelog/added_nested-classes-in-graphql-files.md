- Index classes nested in GraphQL type files. A nested class with a method of its own, a `Struct.new` / `Data.define` subclass, or an exception class (`Error` / `Exception` superclass) declared inside a GraphQL type, mutation or resolver file now becomes a `poro` unit at that path through the owner fallback, so references such as `Types::CartType::DiscountWithCart.new` land on a unit. The same rule now admits exception and value classes nested in a namespace file; a bare class stays a namespace. Run a full extraction after upgrading; incremental extraction then redoes a file's nested units whenever its GraphQL unit is written.
