- Each published generation records a bounded `git_enrichment` summary in its manifest: `available`, `degraded` or `unavailable` with a stable reason (`head_unresolvable`, `no_repository`, `shallow_repository`, `history_read_failed` and others), coverage counted per typed unit (eligible units with facts, units whose history was unavailable, expected exclusions), and how many facts this run refreshed versus retained from an earlier capture. `woods_status` (`index.git_enrichment`), `woods:extract`, `woods:incremental` and `woods:stats` report it; a manifest written before the summary reports `unknown`. A zero-commit file counts as facts, and a source archive without Git still publishes normally. Refs #661.
