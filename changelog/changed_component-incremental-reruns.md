- Incremental extraction re-runs the Phlex and ViewComponent families whenever a Ruby file changes, re-runs view components when a sidecar template changes, and re-runs controllers when a Ruby file under a component directory changes. Their `render` and `slot` edges are resolved against the loaded constant tables, so a newly created component retargets the units that already render it, and no graph edge could reach them otherwise. Units whose output did not change are not rewritten.
