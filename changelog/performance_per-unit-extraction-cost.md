- Every unit's dependency scan rebuilt a set of all model names before looking for `constantize` targets; `ModelNameCache.model_name_set` now holds one frozen set per run, and a source that spells neither `constantize` nor `const_get` is not scanned at all. `SourceNesting.loader_roots` memoizes the expanded autoload roots a managed file is claimed against, and job discovery no longer reads and parses the file of every `ApplicationJob` descendant to admit a class its descent already vouches for. On a 7,753-unit application these were about a fifth of the wholesale job re-run of an incremental extraction, and the same share of every family's extraction in a full run; nothing extracted changes.
