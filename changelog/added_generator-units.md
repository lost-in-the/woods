- Index Rails generators and report their templates (#678). `lib/generators/**` is no longer excluded from the lib extractor: a class inheriting from `Rails::Generators::Base` or `Rails::Generators::NamedBase` is a `lib` unit with `metadata.kind` set to `generator`, and other Ruby there is an ordinary lib unit. Generator templates (`generators/**/templates/**/*.rb`), which are ERB with a Ruby extension, are never extracted and appear in `skipped_files.json` with the reason `template`.
