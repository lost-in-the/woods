- A route file with an invalid UTF-8 byte (a stray Latin-1 byte in a comment) no longer fails the routes extractor. The read refused the file with `ExtractionError`, which dropped its `route_file` unit and marked routes as failed, so every incremental routes re-run aborted publication. The file is now read like other host source: the bad byte is replaced with U+FFFD and the unit is kept.
