- The quick source freshness check stays within its 250ms budget and reaches `current` on small applications. It classified every configuration file with one or two `git` processes of its own (`check-ignore`, then `ls-files --error-unmatch`), which alone could use up the budget, so a check of an unchanged tree stopped part way and answered `unknown`. `GitSourceFilter` now reads the index and the ignore rules for tracked files once (two `git ls-files` calls) and asks Git about an untracked path only once; a root found usable is remembered for the process. The budget now covers the whole check, including reading the manifest, rather than only the walk. Path classification allocates less per file (directory prefix tests without building strings, a reused HMAC context, rake task entries parsed once). On a generated 363-unit app the quick check went from about 270-370ms, 10-26 `git` processes and `unknown` (91-100 of 177 recorded files verified) to 60-175ms, 2-4 processes and `current`. On a generated 4,625-unit app it stays at about 255ms with 2-4 processes instead of 295-370ms with 6, and still reports `unknown` with its `coverage` when the tree does not fit the budget.
