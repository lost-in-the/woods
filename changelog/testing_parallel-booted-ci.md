- `script/parallel-booted` runs booted spec files as separate rspec processes, several at a time: every `:booted_app` file keeps its own Rails process (the file sets that already shared one still do), the incremental-equivalence harness is split by its top-level groups into one line-filtered process per core plus one process per `WOODS_DIFF_SEEDS` seed, and each process gets its own `TMPDIR` and `TEST_ENV_NUMBER`. The children run with fewer, larger GC cycles (`WOODS_BOOTED_GC_TUNING=0` opts out), which the harness's slowest examples measured 4-10% faster. The `rails-matrix` CI job now runs its fifteen former serial single-process steps as two parallel steps, so the booted jobs that were the critical path of every run no longer leave three of four cores idle; locally the pull-request-depth harness went from 10m34s in one process to 2m36s in four. `script/parallel_rspec_timings.json` is regenerated from a current run (722 files; it listed 648), and `script/parallel-rspec --update-timings` reads its report as UTF-8 under any locale.
