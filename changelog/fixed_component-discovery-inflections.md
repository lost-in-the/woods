- Component discovery asks the owning Zeitwerk loader (`cpath_expected_at`) for each file's constant before falling back to `camelize`, so a component named through an inflection (`api_card` => `APICard`) under an autoload-only `app/views` root is loaded and indexed in both the Phlex and ViewComponent families; a file whose expected constant resolves to nothing is now counted as unresolved and logged with the constant that was expected, instead of passing silently.
