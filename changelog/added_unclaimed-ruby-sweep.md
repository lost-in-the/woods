- Sweep Ruby under `app/` that no extractor claims (#672). Helpers, view models, routing constraints, an app-local `app/lib`, and non-component Ruby beside components now become `poro` units with `metadata.discovered_via: "unclaimed_sweep"`, including mixin modules with only instance methods. A path is swept when it matches `config.unclaimed_ruby_paths` (default `["app/**/*.rb"]`), is not under `app/assets` or `app/javascript`, and no `PathDispatcher` file rule owns it; full and incremental extraction share that per-file decision. Classes owned by a class-discovered extractor (controllers, mailers, channels, components, jobs, serializers, GraphQL) are never emitted by the sweep, and a swept class must be canonically declared in its file. Changing `unclaimed_ruby_paths` needs a full extraction.
