- An index can hold absolute, machine-local paths, so don't share, commit or copy an index (or a Markdown export of one) to another machine without sanitizing it first. Extraction makes paths relative only when they are under `Rails.root`. A path outside it is published as it is, and it can include a home directory, a user name or the gem install location (#1012). These fields carry such paths: `file_path` of every unit whose source is outside the app root, which covers `rails_source` and `gem_source` units and models or other classes a gem or framework engine defines (for example Active Storage's models), in the unit file, the type's `_index.json` and `dependency_graph.json` (`nodes.<id>.file_path` and the `file_map` keys); the `file:` front matter of those units' Markdown notes, and the `_woods/dependency_graph.json` copy in the export; `metadata.root_path` and `source_code` of `engine` units; `metadata.middleware_details[].args` and `source_code` of `middleware` units when a middleware takes a path argument, such as the static file root; `metadata.queue` and `metadata.container.queue` of a job whose queue name is a block (the block's label includes its file); and `root` in `manifest.json` and `source_inputs.json`, which is the app root itself. Remove or rewrite these fields before you hand an index to anyone else.
