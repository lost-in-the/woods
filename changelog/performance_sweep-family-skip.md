- Make the unclaimed-Ruby sweep cheap on large applications (#672). A swept file whose only declarations are a class-family class (controller, mailer, component, job...) and its namespace wrappers is now recognized from its governed constant, a line count and a runtime ancestry check, without parsing it, so most controller and component files no longer cost a Prism parse. Class-family base classes are resolved once per run instead of once per class. On a 1,010-file fixture the PORO extractor fell from 1.05s to 0.44s with large controllers, and its cost no longer grows with their size.
