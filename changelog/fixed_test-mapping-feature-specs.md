- Map feature specs without phantom coverage edges (#677). A string describe that is not a constant path (`RSpec.describe 'Widget checkout'`) no longer becomes `subject_class` or a `:test_coverage` edge to a model that does not exist; it is stored as `metadata[:description]`. A task-name describe (`'ledger:rebuild_balances'`) under `spec/tasks/`, `spec/lib/tasks/`, or `test/lib/tasks/` still names its rake task. Capybara `feature` / `RSpec.feature` blocks are read as example groups. Specs under `spec/features/`, or outside every typed directory with a `feature` block or `type: :feature`, get `test_type: :feature` instead of `:unit`; `type: :system` there gives `:system`. Constant-form describes produce the same output as before.
