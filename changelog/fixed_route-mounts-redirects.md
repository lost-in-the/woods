- `RouteExtractor` now emits a unit for every route that dispatches to no controller action, instead of dropping it: mounts, `redirect(...)` routes, and Rack endpoints. Each carries `metadata.kind` (`mount`, `redirect`, `rack_endpoint`) and what it points at (`metadata.app`; `redirect_target`, which is `"dynamic"` for a block, and `redirect_status` for redirects). The kind is appended to the identifier (`"ANY /cable (mount)"`, `"GET / [subdomain=www] (redirect)"`), so controller-route identifiers and units are unchanged. These units emit no `route_dispatch` edge; an engine mount links to its `engine` unit with `via: :mount`. A controller route whose action is a dynamic path segment is still skipped.
