- Controller extraction no longer publishes a reloaded controller's previous class. A reload leaves the old class object in `ActionController::Base.descendants` under the name its replacement holds, and on Rails 6.0/6.1 the extractor could publish that stale class instead of the live one, so a filter added to a base controller disappeared from a full extraction while an incremental run kept it. Discovery now skips a class its name no longer resolves to, as component and job discovery already did.
