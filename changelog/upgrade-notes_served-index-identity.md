- `woods-mcp-start` now refuses an index another checkout of the repository recorded: when the checkout containing the index's recorded root (or, without one, the index directory) differs from the checkout containing the launcher's working directory, it exits 1 naming both. Pass `--allow-mismatch` or set `WOODS_MCP_ALLOW_MISMATCH=1` to serve it anyway, with a warning. Nothing is refused when either checkout cannot be determined (launched outside a checkout, or an index outside any reachable checkout), and branch differences only warn. `woods-mcp` itself never refuses. The `woods_status` report gains a leading `identity` key, and `instructions` no longer start with "Start with woods_status": they lead with the identity line.
