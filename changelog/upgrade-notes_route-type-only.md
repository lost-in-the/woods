- `route` now means the route unit type only (#969). Before, it also matched the `route_file` units that share the `routes/` directory, in `search` (`types: ["route"]`), `recent_changes`, `Woods::PublishedIndex#unit(type: 'route')` and `#units(type: 'route')`. A caller that wanted route files as well should also pass `route_file`, or list with no type and filter on each entry's `"type"`; `routes` is not accepted as a type. `graphql` and `rails_source` stay family aliases and still select every type in their directory. `recent_changes` now labels each result with its unit's own type (`route_file`, `gem_source`, `graphql_mutation`) instead of its directory name, and accepts those types as filters. Older indexes whose `routes/` entries carry no `type` still list correctly; each unit is read to learn its type.
