- `trace_flow` and `woods:flow` accept model event entry points (W-5, #755): `Post@create`, `Post@update`, `Post@destroy`, `Post@after_commit(create)` and `Post@after_commit`. The flow lists the model's callbacks for the event in the order Rails runs them, keeping only those whose `on:` scope admits it, and expands each callback the model defines, so an `after_commit` that enqueues a job continues into the job. A callback the unit does not define is listed with `unexpanded` and its reason. Assembled on demand; `precompute_flows` still covers controller actions only.
