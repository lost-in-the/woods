- `woods:embed` applies the documented `:in_memory` fallback for an unset `metadata_store` or `graph_store` before it records `woods.json` and now always writes the metadata dump, so the packaged Index server boots semantically from such an index instead of failing on blank store types. Blank store types in snapshots written by earlier runs are treated as unset, and a snapshot naming a store adapter the gem cannot build fails with a one-line `BootstrapError` instead of a backtrace.
