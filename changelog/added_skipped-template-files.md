- `skipped_files.json` lists template files a sweep glob names. Add a glob such as `config/**/*.erb` to `config.unclaimed_ruby_paths` and each ERB, HAML, Jbuilder, or Slim file it matches that no unit covers is reported with a reason: `non_view_template` (a template outside the view directories, such as a crontab template), `unsupported_template_engine` (a view no registered engine reads), or `rejected_by:view_templates`. A template beside the Ruby file of a unit (a component sidecar) counts as covered. Templates are never swept as Ruby, and the default globs name none, so the report is unchanged until a glob is added.
