- Model callback operations (`metadata[:callbacks][].side_effects[:operations]`) now report the line in the file the callback body lives in, plus that file. A callback defined in a concern was numbered in the analyzer's joined model-and-concern text, so its lines ran past the end of the model file and named no file. A model-defined callback reports the model's file; a concern-defined one reports the concern's file and line; a body read from outside the application root reports neither rather than a wrong line.
