- The managed `woods:watch` launcher now starts under a POSIX locale (`LC_ALL=C`) when the application root or its environment holds a non-ASCII character. Its guardian runs before Bundler and Rails, so its config read took the locale's US-ASCII encoding and parsing raised before the application started. The daemon's claim file is also read as bytes now, so a non-ASCII byte in it no longer raises past the stale-claim check.
