- Action chunks now publish the method body Ruby dispatches: the per-file method map is keyed by `[name, line]` and selected through `source_location`, so a redefined action, two classes in one file sharing an action name, or a `class << self` def beside the instance method no longer publish the first `def` by that name. Flow documents index class methods (`def self.x`) and no longer fall back to the whole unit when the called method is not defined locally, which reported unrelated operations as the method's. An enqueue nested in another call's arguments (`Audit.record(NotifyJob.perform_later(...))`) now yields its `async` operation.
