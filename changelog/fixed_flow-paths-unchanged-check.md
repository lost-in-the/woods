- An incremental run no longer rewrites every flow-bearing controller in its blast radius when nothing in the controller changed (#994). The unchanged check compared the published `metadata.flow_paths` against a fresh unit that never has it yet, so those controllers were written again with only `extracted_at` different, and `Re-extracted N affected units` counted them. With `precompute_flows` on and a published flow family, the check now leaves the annotation out. The flow refresh still takes each retained controller, and rewrites it, and counts it, only when its flow annotation really changes. With the gate off, or no published flow family, the annotation is compared as before.
