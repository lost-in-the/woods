- The console SQL gate now ends a PostgreSQL `--` comment at a carriage return, as PostgreSQL itself does. It used to treat everything after `--` up to the next newline as comment, so `SELECT a FROM ok --x\r UNION SELECT s FROM secrets` reached the database with the `secrets` read live while the table gate, the function allowlist and the statement checks saw only `SELECT a FROM ok`. This affected only applications that enabled the console SQL tools (`console_embedded_read_tools` or `embedded_read_tools:`). MySQL and SQLite comments still end only at a newline, as those servers do.
