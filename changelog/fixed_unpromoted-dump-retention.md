- Embedding dump retention (`dump_retention_count`) now counts only dumps that were promoted to `dumps/latest`. A dump left behind by a run that failed or was killed before promotion used to take a place in the window, so a few leftovers could delete promoted dumps early. Each promoted dump now carries a `.promoted` marker; a dump without one is kept out of the count and removed only after it has sat untouched for 24 hours, so a writer still dumping in another process never loses its directory. Dumps written by an earlier Woods, older than the first marked one, still count as before.
