- **Private writer stages in `payloads/`.** A run now builds its payload in `payloads/.stage-<n>-<token>` and renames it to `gen-<n>` when it publishes. Readers, pins and retention only consider `gen-<n>`, as before. A shell or Python reader that lists `payloads/` should ignore entries that do not match `gen-<n>`; follow `generation.json` instead of listing the directory. A run that publishes nothing removes its stage; a stage left by a crashed writer is removed after 24 hours. See [writer stages and lock takeover](docs/INDEX_LAYOUT.md#writer-stages-and-lock-takeover).
