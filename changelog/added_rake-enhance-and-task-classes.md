- Index more of the Rake DSL. `Rake::Task["a"].enhance(["b"])` adds a `task_dependency` edge from `a` to `b` and lists the enhancing file in `metadata.enhanced_in`; an enhanced task that no configured file defines still gets a unit, with `metadata.kind: "enhancement"`. `execute` joins `invoke` as a `task_invoke` edge. Task classes such as `RSpec::Core::RakeTask.new(:docs)` become units with `metadata.task_class`, and a definition inside `if`/`unless` records the condition in `metadata.conditions`. `multitask`, `file`, `directory` and `rule` definitions are indexed, and every rake unit carries `metadata.kind`.
