- Report swept Ruby files that produced no unit (#672, #663, #664, #673). `Woods::SkippedFiles` lists every `.rb` file under `config.unclaimed_ruby_paths` and `app/models` that no unit names, each with a reason: `rejected_by:<extractor>` (a file rule or class-discovered extractor owns it and emitted nothing), `parse_error`, `no_declaration`, `namespace_only`, or `not_owned` (unloaded, reopened from another file, or methods defined elsewhere). The report is a pure function of the tree and the unit paths, so full and incremental runs agree. `woods:extract` prints a one-line summary and `woods:validate` prints it as information, never as a failure, from the published `skipped_files.json`, which every full and incremental run writes into the generation payload. An incremental run whose only change is a skip reason still publishes the updated report; a run that changes nothing stays a no-op.
