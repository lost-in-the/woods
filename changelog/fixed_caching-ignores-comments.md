- `CachingExtractor` ignores cache calls inside comments: Ruby `#` and `=begin`/`=end` in `.rb` and `.jbuilder` files, ERB `<%# ... %>` and `<% # ... %>`, and HAML `-#` silent comments (with their indented block) and `- # ...` lines. A commented-out call no longer counts toward `cache_calls` or `cache_strategy`, and a file whose only cache calls are commented out is no longer a caching unit.
