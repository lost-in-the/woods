- `console_sql` now caps results. A call without `limit` returns at most 100 rows, and a requested `limit` is clamped to 1000. Both values are host-configurable through `console_sql_default_limit` and `console_sql_max_limit`. The result gains a `completeness` object (`status`, `reason`, `has_more`) so truncation is reported rather than silent. `EXPLAIN` stays uncapped and still rejects `limit`; the statement timeout is unchanged.
