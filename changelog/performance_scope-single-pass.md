- Building a package or source-path scope (`codebase_retrieve` with `packages:`/`source_paths:`, and the scoped Index Server tools) reads and validates each metadata record once. It used to deep-copy every record through a JSON round trip before validating it, validate the contributor records once for the package check and twice more per record for eligibility, then copy the eligible subset again; the scope's own store now makes the one copy it keeps. On a 6,139-unit index a `lib/` scope builds in about half the time and an empty scope in about a third, with identical eligible keys and records.
