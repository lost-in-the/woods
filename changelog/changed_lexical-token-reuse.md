- Explicit lexical retrieval (`WOODS_RETRIEVAL_MODE=lexical`) rebuilds its snapshot after a new publication much faster in a long-running server: it re-tokenizes only the units whose indexed text changed and reuses the rest from the previous build in memory. Answers are byte-identical to a cold build. Each unit file is now parsed once into frozen data shared by the index and its metadata store, which removes two JSON copies per unit and lowers resident memory. A new process's first query is unchanged in cost. Nothing is written to disk.
