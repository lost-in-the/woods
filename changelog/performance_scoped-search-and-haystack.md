- Scoped vector search (`codebase_retrieve` with `packages:`/`source_paths:`) makes one native call to the in-memory vector store instead of one per hundred eligible ids: the adapter now declares its id-filter bound (`id_filter_batch_size`, nil for in-memory, 100 by default for adapters that bind every id), so a 5,990-id scope no longer costs 60 full buffer scans. The in-memory metadata store serialises each record's whole-record search haystack once instead of on every keyword search, dropping it when the record changes or goes away.
