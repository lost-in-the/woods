- Test-mapping and controller dependency edges no longer name typed units that do not exist (woods#809). A Minitest integration or system test class names a scenario (`FollowPagesTest`), so it becomes the unit's `description` and links no `test_coverage` target, unless its suffix names a unit type (`UsersControllerTest`). A helper subject (`SessionsHelper`) is linked as the `poro` the PORO extractor publishes, not a `model`. A controller's template render (`render "static_pages/home"`) no longer publishes a `view` edge: no unit has that type, and which `view_template` the spelling reaches depends on the files present, which a controller re-extraction does not track. `metadata.action_facts` keeps each render as written.
