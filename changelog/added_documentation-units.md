- Index project documentation as `doc` units (#676). Markdown under `config.documentation_paths` (default `README.md`, `docs/**/*.md`, `doc/**/*.md`, `CLAUDE.md`, `AGENTS.md`, `.claude/rules/**/*.md`, `.claude/skills/**/*.md`, `.github/**/*.md`, minus `config.documentation_exclude`) becomes one unit per file with its title, heading outline, front matter, links and word count, chunked by heading section so retrieval returns the relevant section. Inline code and code fence mentions that name an indexed unit (a constant, a file path, a rake task, a route) become `documents` edges, and relative links between documents become `doc_link` edges, so `dependents` on a unit lists the documents that mention it. Mentions that name nothing are recorded as unresolved and produce no edge. A symlink to another indexed document is recorded as that document's alias (`metadata.aliases`) instead of a second unit. Resolution runs after every extractor in full and incremental runs, so an unchanged document follows its targets as they appear and disappear.
  Documentation units take no part in PageRank, the incremental blast radius or `graph_analysis.json`. Retrieval includes them by default; `config.retrieve_documentation = false` or `WOODS_RETRIEVE_DOCUMENTATION=0` excludes them unless a caller asks for `types: ["doc"]`. Published source is redacted with the Console scanner's credential shapes and the URL-userinfo pass used for configuration source, best effort. Source capture and the watch daemon now walk `.claude/rules`, `.claude/skills` and `.github`. Run a full extraction after upgrading: the dispatch rules changed, and incremental runs refuse the old baseline.
