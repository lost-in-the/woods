Woods documentation fonts — local copies, no network font dependency

These unmodified WOFF2 files and their copyright/license notices come from
lost-in-the/woods-map, vendor/fonts/, as documented in its README.md.

Inter: @fontsource/inter 5.3.0 (Inter 4.1), latin and latin-ext subsets,
normal weights 400, 500 and 700. Source: https://www.npmjs.com/package/@fontsource/inter
License: OFL-1.1, included verbatim in inter/OFL.txt.

Fira Code: release 6.2, complete Regular, Medium and Bold WOFF2 files.
Source: https://github.com/tonsky/FiraCode/releases/tag/6.2
License: OFL-1.1, included verbatim in fira-code/OFL.txt.

The relative @font-face URLs and Inter unicode ranges follow woods-map's
app/assets/stylesheets/woods_map/fonts.css. Fonts use font-display: swap;
system sans-serif and monospace fallbacks remain available if loading fails.
No font is renamed, subsetted, converted or fetched during a site build.
